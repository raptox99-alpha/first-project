# Restora - Restaurant Website

Welcome to *Restora*, my very first web development project created while learning frontend development! 

### What I Built & Learned
* *Layout & Styling:* Designed a responsive dark-themed restaurant website using *HTML5*, *CSS3*, and *Bootstrap 5*.
* *Navigation & Footer:* Built smooth single-page scrolling sections and a structured multi-column footer with *Font Awesome* icons.
* *Table Booking Form (Beginner JS):* Added a reservation form with basic *JavaScript* (which I am currently learning) to validate inputs and display a dynamic confirmation modal.

### Technologies Used
* HTML5
* CSS3
* Bootstrap 5
* Font Awesome
* Basic JavaScript (Currently Learning)

This project marks the beginning of my web development journey.
